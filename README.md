# DentaGraph Research Hub

Curated research resources for **DentaGraph**, a multispecialty, multimodal dental multi-agent clinical decision-support project.

This repository collects:

- dental agent and multi-agent papers
- public and request-access dental datasets/benchmarks
- official code repositories
- evaluation frameworks relevant to DentaGraph
- a comparison matrix showing how DentaGraph differs from current dental agent systems

## Main DentaGraph benchmark

### DentCaseBench
Patient-level, multispecialty benchmark created for dental clinical reasoning and multi-agent evaluation.

Current study design:
- 226 patient-level cases
- 10 dental specialties
- publication-level frozen splits
- multimodal cases with linked images
- development, public-validation, private-validation, and hidden-test partitions

Research folder:
https://drive.google.com/drive/folders/1q5fuYBblt_SKxDFlv5v5vblSSgtaxzCd?usp=sharing

## Scope

This repository is for research and evaluation. It is not intended for direct patient care or autonomous clinical decision-making.
