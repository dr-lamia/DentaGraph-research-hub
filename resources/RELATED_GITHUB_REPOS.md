# Related GitHub Repositories

Official or primary code repositories useful for DentaGraph research.

## Dental agent systems

### OralAgent
https://github.com/isjinghao/OralAgent

Purpose:
Interactive dental-image agent integrating reasoning, visual tools, and dental knowledge retrieval.

### OPGAgent
https://github.com/Zhaolin-Yu/OPGAgent

Purpose:
Auditable agentic panoramic radiograph interpretation with hierarchical evidence gathering and consensus.

### OralGPT
https://github.com/isjinghao/OralGPT

Purpose:
OralGPT / MMOral ecosystem; useful for MMOral-Bench and OralGPT-Plus-related resources.

## Dental multimodal models

### DentVLM
https://github.com/ZJUI-AI4H/DentVLM

Purpose:
Multimodal vision-language model for comprehensive dental diagnosis; includes inference/evaluation code and example formats.

## Notes

- Always confirm the license of code, model weights, and datasets before redistribution or derivative use.
- Some clinical datasets referenced in papers are restricted-access even when code is public.
- Do not copy patient data into this repository unless the release terms explicitly permit redistribution.
